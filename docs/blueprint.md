# **App Name**: Caimanera Randomizer

## Core Features:

- Game Configuration: Users can specify the number of players per team (e.g., 4v4, 5v5) and the total number of participants for the game.
- Player Roster Input: A text area for users to paste or type in the complete list of player names, with each name on a new line.
- Random Team Allocation: An algorithm that takes the player list and configuration to randomly divide participants into balanced teams, mimicking a roulette selection.
- Generated Teams Display: Clearly presents the randomly formed teams, listing each player under their assigned team.
- Dynamic Team Name Generator: Leverages a generative AI tool to suggest creative and fun team names based on the sport or competitive themes.
- Copy Team Lists: Provides a convenient button to copy the entire generated team list to the clipboard for easy sharing with others.

## Style Guidelines:

- Primary color: #26A5CF (HSL(190, 70%, 45%)). A vibrant, energetic blue evoking activity and clarity.
- Background color: #F3F8FA (HSL(190, 15%, 96%)). A very light, desaturated blue to provide a clean and fresh backdrop.
- Accent color: #28AE7B (HSL(160, 60%, 40%)). A lively green that offers a clear, harmonious contrast for highlights and actionable elements.
- Headline and body font: 'Inter' (sans-serif), chosen for its modern, clean lines and excellent readability for lists and functional text.
- Use icons that are clean, contemporary, and clearly related to sports, team formation, or randomization.
- A clear and intuitive layout with distinct sections for input (configuration and player list) and output (generated teams).
- Subtle, smooth animations to enhance the user experience, particularly for the 'roulette' effect during team generation.
