
# Caimanera Elite | Tournament Randomizer

Organiza tus partidos con el motor de sorteos más avanzado. Estética Champions League para tus encuentros amateur.

## Cómo empezar

Este proyecto está optimizado para funcionar con cualquier gestor de paquetes moderno.

### Instalación de dependencias

```bash
# Con npm
npm install

# Con yarn
yarn install

# Con pnpm
pnpm install
```

### Desarrollo

Para iniciar el servidor de desarrollo:

```bash
npm run dev
# o
yarn dev
# o
pnpm dev
```
